# ✈️ Travel Booking Website

A modern and responsive travel website built using React.js and Vite.

## 🛠️ Technologies Used
- React.js
- Vite
- JavaScript
- HTML5
- CSS3

## ✨ Features
- Attractive Homepage
- Explore Destinations
- Featured Destinations
- Booking Section
- Wishlist
- Travel Plans
- Testimonials
- Responsive Design

## 📁 Project Structure
- `src/components` - Reusable components
- `src/pages` - Website pages
- `src/assets` - Images and assets
- `src/styles` - CSS files

## 💻 Installation & Setup

```bash
git clone https://github.com/Sanskruti-dev6/travel-booking.git
cd travel-booking
npm install
npm run dev
```
